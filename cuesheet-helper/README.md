# HANFLIX 큐시트 체크 (2026 학부합창대회)

각 학부가 **자기 구글 드라이브에 만든 큐시트 시트 링크**를 넣으면 **항목별 피드백**을 주고, 고칠 수 있는 부분은 직접 고친 **수정본을 원본과 별도의 새 시트**(새 구글 시트 또는 2026 2차 큐시트 양식 그대로의 .xlsx)로 만들어 주는 웹사이트입니다. 첨부한 원본 시트는 읽기만 하고 바꾸지 않으며, 특정 시트(예: TFT 전체 큐시트)에 묶여 있지 않습니다. 디자인은 대회 로고(HANFLIX, #0060D1 파랑 · 검정→남색)를 따릅니다.

## 진행 순서

1. **첨부** — 학부 큐시트 시트의 공유 설정을 '링크가 있는 모든 사용자 · 뷰어'로 바꾸고 링크를 넣습니다. 탭이 여러 개면 큐시트가 있는 탭을 고릅니다.
2. **피드백** — 결과 화면에서 항목별 피드백(근거·대안)을 보고, 필요하면 그 자리에서 고칩니다.
3. **수정본 받기** — '새 구글 시트로 만들기'를 누르면 내 구글 드라이브에 새 빈 시트가 열리고, 2026 2차 양식 그대로인 수정본 엑셀이 내려받아집니다. 새 시트에서 **파일 → 가져오기 → 업로드**로 그 파일을 고르고 **스프레드시트 바꾸기 → 데이터 가져오기**를 누르면 열 너비·셀 색·글꼴·테두리·셀 병합까지 그대로 들어갑니다. (복사·붙여넣기는 열 너비가 빠지고 글자색이 흐려져 쓰지 않습니다.)

- 배포 주소: https://cuesheet-feedback-2026.netlify.app
- Netlify 프로젝트: `cuesheet-feedback-2026` (운영 주소 공개, 미리보기 배포는 Netlify 팀 로그인 필요)

## 화면 구성

| 주소 | 화면 |
|---|---|
| `#/` | 홈(큐시트 첨부) — 우리 학부 큐시트의 구글 시트 링크 입력과 '피드백 받기'만. 시트를 열 수 없으면 공유 설정을 바꾸라는 안내가 나옴. 바닥글은 '2026 학부합창대회 TFT' |
| `#/result` | 피드백 결과 — 큐시트를 첨부하면 이어서 나오는 화면(상단 메뉴에는 없음). 맨 위에 첨부한 원본(구글 시트 제목 › 탭과 '시트 열기' · 행 수 · 첨부 시각 · 원본은 바꾸지 않음), 점검 기준, 필수·권장·논의 중 개수, 무대 시간(11분), '수정본 받기'(새 구글 시트로 만들기 · 엑셀 파일로 받기 · 검토용 엑셀 · 피드백 메시지 복사), '다른 큐시트 첨부'. 그 아래 항목 8개(Run Time, 무대·인원, 세부 내용, 개사, 음향·FD, 화면, 조명, 양식)가 접힌 목록으로 있고, 눌러서 펼치면 피드백(근거·대안), 바로 고치기, 자동 수정 끄기가 나옴. Run Time에는 무대 시간 막대, 조명에는 FX 지정 |
| `#/sheet` | 전체 표 — 수정본/원본, 칸 바로 수정, 행 추가·삭제 |
| `#/guide`, `#/guide/{basic,time,content,sound,light,check}`, `#/example` | 주제별 짧은 가이드, 모범 예시 |

상단 메뉴는 홈 · 가이드뿐입니다. 피드백 결과는 따로 있는 메뉴가 아니라 큐시트를 첨부했을 때 이어지는 단계로만 나오고, 다른 큐시트를 점검하려면 결과 맨 위 '다른 큐시트 첨부'(또는 홈)를 누릅니다. 예전 주소(`#/check`, `#/check/{항목}`, `#/report`, `#/download`)는 `#/result`로 넘어가며, 항목을 가리키던 주소면 그 항목을 펼쳐서 보여 줍니다.

불러온 큐시트는 브라우저 탭(sessionStorage)에만 남고, 새로고침해도 이어서 볼 수 있습니다.

## 점검 기준

| 기준 자료 | 반영 내용 |
|---|---|
| 2026 2차 큐시트 양식(4행 붉은 안내) | 열 구성 A~P, 빈칸 금지(X/유지), 총 13분 = 인트로 2분 + 무대 11분, 글꼴·크기·색·병합·틀 고정 |
| 학부 디렉터 OT '무대 큐시트 작성 예시' | Run Time `00:00 ~ 00:04 (4초)`, 무대·대기 인원·세부 내용(언제·어디서·누가·무엇을·어떻게), 개사(Run Time에 맞춰), 음향/FD, 화면, 공통 항목 셀 병합 |
| 2026 조명 큐시트 작성 가이드 | 무대·상단 = 구역/색상/밝기, Pin1~4 = 색 변경 불가·위치 고정·1명용, FX1·FX2 2개만(Details에), 전환 방식·영상 시간 기준·객관적 시점 |
| 2025·2026 공시 큐시트 | 모범 작성 방식. 2025는 음향/FD만 참고 |
| 2026 2차 TFT 피드백 메모 | 단시·Runtime 분리, 조명 시간 Run Time 맞추기, 조명 X 표시, 논의 중 표시, 양식 유지 |

실제 학부 큐시트 내용은 사이트에 넣지 않았습니다. 예시는 모두 가상 학부입니다.

```

  index.html            상단 바 + 화면 틀
  assets/js/app.js      해시 라우팅과 각 화면
  assets/js/ui/         아이콘·HANFLIX 워드마크, 표 그리기, 가이드 내용
  assets/js/engine/     분석·자동 수정 엔진 (브라우저와 Node 공용)
  assets/js/io/         구글 시트 xlsx 읽기, 2026 2차 양식 엑셀 만들기
netlify/functions/
  sheet.mts             공개 구글 시트를 내려받아 전달 (/api/sheet) — 스프레드시트 제목도 x-sheet-title로 함께 전달
  ai-review.mts         (선택) Claude로 문장·조명 대안 (/api/ai-review)
tests/engine.test.mjs   npm test
```

## AI 대안 기능 켜기 (선택)

규칙 기반 피드백과 수정본은 API 키 없이 동작합니다. Netlify 프로젝트 설정 → Environment variables에 `ANTHROPIC_API_KEY`(범위: Functions)를 넣고 다시 배포하면 결과 화면 맨 위 버튼 줄에 'AI 대안'이 나타납니다. 모델은 `claude-opus-5-5`, 서버 측 대체 모델(`fallbacks: "default"`)을 켜 두었습니다. AI를 쓰면 무대별 큐시트 내용이 Anthropic API로 전송됩니다.
