# HANFLIX 큐시트 체크 (2026 학부합창대회)

각 학부가 **자기 구글 드라이브에 만든 큐시트 시트 링크**를 넣으면 **항목별 피드백**을 주고, 학부가 **반영할 피드백을 고르면** 고른 것만 반영된 큐시트를 **원본과 별도의 새 구글 시트**(2026 2차 큐시트 양식 그대로)로 만들어 주는 웹사이트입니다. 첨부한 원본 시트는 읽기만 하고 바꾸지 않으며, 특정 시트(예: TFT 전체 큐시트)에 묶여 있지 않습니다. 디자인은 대회 로고(HANFLIX, #0060D1 파랑 · 검정→남색)를 따릅니다.

## 진행 순서

1. **첨부** — 학부 큐시트 시트의 공유 설정을 '링크가 있는 모든 사용자 · 뷰어'로 바꾸고 링크를 넣습니다. 탭이 여러 개면 큐시트가 있는 탭을 고릅니다. 원본 시트는 읽기만 합니다.
2. **반영할 피드백 고르기** — 결과 화면에 총평과 항목별 피드백이 나옵니다. 피드백마다 **원래 → 수정 후**를 보고 **반영 / 반영 안 함**을 고릅니다.
   - **자동 정리**(Run Time·조명 표기, 빈칸 X/유지, 셀 병합 등 형식): 처음부터 반영으로 골라져 있고 끌 수 있음
   - **반영하면 이렇게**(그 칸에 들어갈 문구가 정해진 수정): 시트 값만으로 계산한 확실한 것은 반영, 예시(`[ ]`, 화면에서는 파란 글씨)가 들어가는 것은 처음에 반영 안 함 — 골라서 반영. '수정 후 문구 고치기'로 고친 문구로 반영 가능
   - **직접 고치기**(11분 맞추기, FX 효과 고르기 등 학부가 정할 것): 반영할 수 없음 → 받은 시트에서 고침
   - 한꺼번에: 수정요망 모두 반영 · 모두 반영 · 모두 반영 안 함 · 처음 선택으로, 항목별 '이 항목 모두 반영'. 같은 칸을 바꾸는 항목을 함께 고르면 알려 주고 아래쪽 문구가 들어감
   - '이 무대에 맞춘 제안' 중 칸에 넣을 수 있는 것(간주 구간 마이크 OFF/ON 시각, 절정 볼륨, 절정 밝기)도 골라서 반영
   - 미리보기(`#/sheet`)로 반영한 모습을 2026 양식 표로 확인
3. **피드백 반영한 구글 시트 받기** — '피드백 반영한 구글 시트 만들기'를 누르고 구글 계정으로 로그인('허용')하면, 고른 피드백만 반영된 큐시트를 2026 2차 양식 엑셀로 만든 뒤 **구글 시트로 변환해 학부 계정의 드라이브에 새 파일**로 올리고 바로 엽니다(열 너비·셀 색·글꼴·테두리·병합 유지). 권한은 `drive.file`(이 사이트가 만든 파일에만 접근)뿐이고 첨부한 원본은 바뀌지 않습니다. 예시가 들어간 칸과 '(작성 필요)' 칸은 붉게 표시되고, 원하면 반영으로 바뀐 칸을 노란색으로 표시합니다.

### 구글 로그인 설정 (처음 한 번)

새 구글 시트를 바로 만들려면 Google OAuth 클라이언트 ID가 필요합니다. 없으면 대신 반영본 엑셀을 내려받아 새 시트에서 '파일 → 가져오기'로 넣도록 안내합니다.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 만들고 **Google Drive API**를 사용 설정합니다.
2. **OAuth 동의 화면**: 사용자 유형(학부 디렉터가 학교 계정만 쓰면 '내부', 개인 계정도 쓰면 '외부' 후 게시), 앱 이름 'HANFLIX 큐시트 체크', 범위 `.../auth/drive.file`.
3. **사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션**, 승인된 JavaScript 원본에 `https://cuesheet-feedback-2026.netlify.app`.
4. 만든 클라이언트 ID(비밀값 아님)를 Netlify 환경 변수 `GOOGLE_CLIENT_ID`(범위: Functions)에 넣고 다시 배포합니다. 사이트는 `/api/config`로 이 값을 읽습니다.

- 배포 주소: https://cuesheet-feedback-2026.netlify.app
- Netlify 프로젝트: `cuesheet-feedback-2026` (운영 주소 공개, 미리보기 배포는 Netlify 팀 로그인 필요)

## 화면 구성

| 주소 | 화면 |
|---|---|
| `#/` | 홈(큐시트 첨부) — 우리 학부 큐시트의 구글 시트 링크 입력과 '피드백 받기'만. 시트를 열 수 없으면 공유 설정을 바꾸라는 안내가 나옴. 바닥글은 '2026 학부합창대회 TFT' |
| `#/result` | 피드백 결과 — 큐시트를 첨부하면 이어서 나오는 화면(상단 메뉴에는 없음). 맨 위에 진행 단계(① 첨부 ② 반영할 피드백 고르기 ③ 피드백 반영한 구글 시트 받기), 첨부한 원본(구글 시트 제목 › 탭 · '시트 열기' · 행 수 · 첨부 시각 · 원본은 바꾸지 않음), 점검 기준, 수정요망 개수, 무대 시간(11분), 반영 선택 개수. 그 아래 총평, '반영할 피드백 고르기'(한꺼번에 고르기 버튼과 항목 종류 설명) + 항목 8개(접힌 목록, 펼치면 카드마다 원래 → 수정 후 · 반영 / 반영 안 함 · 수정 후 문구 고치기 · 근거, 참고 — 골라서 반영, 이 무대에 맞춘 제안, 자동 정리, FX 지정), 그다음 '피드백 반영한 구글 시트 받기'(만들기 · 미리보기 · 엑셀 파일로 받기 · 검토용 엑셀 · 피드백 메시지 복사 · 바뀐 칸 노란색 표시). 화면 아래 고정 막대에 반영 개수와 '구글 시트 만들기' |
| `#/sheet` | 미리보기 — 피드백 반영본 / 원본을 2026 양식 표로(읽기 전용), 반영으로 바뀐 칸 · 직접 채울 칸 · 논의 중 · 아직 남은 수정요망 표시, '피드백 반영한 구글 시트 만들기' |
| `#/guide` | 작성 가이드 첫 화면 — 홈에서 제출까지 7단계 흐름(무대 구상 → 음향·조명 구성 → 양식에 채우기 → 제출 전 체크 → 링크로 피드백 → 반영할 피드백 고르기 → 반영된 구글 시트 받기), '2026 새 기준 · 피드백 방식' 상자(주인공 동선·의상·위치, 노래에 맞춘 마이크, 음향·조명 구성, 항목별 반영 고르기), 주제 묶음 3개(방향 잡기 · 칸별 작성법 · 제출과 피드백) |
| `#/guide/{process,plan}` | 방향 잡기 — 작성 순서(단계별 할 일과 사이트가 해 주는 것 / 학부가 채울 것), 무대 연출 계획(개사 분위기 → 상단 색, 곡 흐름 → 밝기, 사람 배치 → Pin 자리, 주인공 동선·의상·위치, 노래 → 마이크, 모범 예시 무대 1로 정리한 표). 결과 화면의 '이 무대에 맞춘 제안'과 같은 기준 |
| `#/guide/{basic,time,content,sound,light}` | 칸별 작성법 — 규칙과 '자주 받는 피드백'(원래 → 수정 후, 결과 화면 카드와 같은 모양). 새로 추가된 기준에는 '새 기준' 표시 |
| `#/guide/{check,feedback}`, `#/example` | 제출 전 체크(5묶음 17가지), 피드백 고르고 받기(카드 읽기 · 항목의 세 종류 · 고르고 구글 시트로 받는 순서), 모범 예시 |

결과 화면 항목마다 기준 줄 끝의 '가이드'는 그 칸의 작성법으로, '이 무대에 맞춘 제안'의 '구성법'은 무대 연출 계획으로 이어집니다. 첨부한 큐시트와 고른 반영 여부·고친 문구는 브라우저 탭(sessionStorage)에만 남습니다.

상단 메뉴는 홈 · 가이드뿐입니다. 피드백 결과는 따로 있는 메뉴가 아니라 큐시트를 첨부했을 때 이어지는 단계로만 나오고, 다른 큐시트를 점검하려면 결과 맨 위 '다른 큐시트 첨부'(또는 홈)를 누릅니다. 예전 주소(`#/check`, `#/check/{항목}`, `#/report`, `#/download`)는 `#/result`로 넘어가며, 항목을 가리키던 주소면 그 항목을 펼쳐서 보여 줍니다.

불러온 큐시트는 브라우저 탭(sessionStorage)에만 남고, 새로고침해도 이어서 볼 수 있습니다.

## 원래 → 수정 후

피드백 카드는 접힌 상태에서도 `원래 … → 수정 후 …` 한 줄을 보여 주고, 펼치면 두 칸으로 나란히 보여 줍니다(휴대폰에서는 위아래).

| 표시 | 뜻 |
|---|---|
| 자동 정리 | 형식을 맞추는 수정. 반영하면 들어갈 값 (여러 칸이면 칸별 예도 함께) |
| 자동 정리 · 반영 안 함 | 그 자동 정리를 반영 안 함으로 고른 경우 |
| 반영하면 이렇게 | 반영하면 그 칸에 들어갈 문구. 그 학부의 Run Time·가사·인원·조명 칸에서 찾은 값으로 만들고, 학부만 알 수 있는 부분은 파란 글씨(엑셀·메시지·받은 시트에서는 `[ ]`, 붉은 칸)로 표시 |
| 고친 문구 | '수정 후 문구 고치기'로 학부가 고친 문구 — 이 문구로 반영 |
| 고칠 방향 | 칸 하나로 보여 줄 수 없는 것(예: 무대 시간 11분 40초 → 11분 이내) — 직접 고치기 |

피드백 메시지(항목마다 `[반영]` · `[반영 안 함]` · `[직접 고치기]`)와 검토용 엑셀('피드백 목록'의 원래 · 수정 후 · 반영 열)에도 같은 내용이 들어갑니다.

| 기준 자료 | 반영 내용 |
|---|---|
| 2026 2차 큐시트 양식(4행 붉은 안내) | 열 구성 A~P, 빈칸 금지(X/유지), 총 13분 = 인트로 2분 + 무대 11분, 글꼴·크기·색·병합·틀 고정 |
| 학부 디렉터 OT '무대 큐시트 작성 예시' | Run Time `00:00 ~ 00:04 (4초)`, 무대·대기 인원·세부 내용(언제·어디서·누가·무엇을·어떻게), 개사(Run Time에 맞춰), 음향/FD, 화면, 공통 항목 셀 병합 |
| 2026 조명 큐시트 작성 가이드 | 무대·상단 = 구역/색상/밝기, Pin1~4 = 색 변경 불가·위치 고정·1명용, FX1·FX2 2개만(Details에), 전환 방식·영상 시간 기준·객관적 시점 |
| 2025·2026 공시 큐시트 | 모범 작성 방식. 2025는 음향/FD만 참고 |
| 2026 2차 TFT 피드백 메모 | 단시·Runtime 분리, 조명 시간 Run Time 맞추기, 조명 X 표시, 논의 중 표시, 양식 유지 |
| TFT 조명 Details 기준 | **학부가 주인공을 쓰는 무대만**: 조명 Details에 주인공의 동선(어디에서 어디로) · 의상 · 위치(어느 Pin 자리)를 구체적으로 — 빠진 것을 수정요망으로 알려 주고, 세부 내용에 적힌 동선으로 수정 후 예시를 만듦. 솔로만 있는 무대에는 적용하지 않음 |
| 무대 내용 · 개사 분석 | 노래하는 구간인데 마이크가 없음, 노래하는 주인공·솔로에게 무선(핸드) 마이크가 없음 → 수정요망 |

### 음향 · 조명 제안 (무대 내용 · 개사 분석)

무대마다 출연 구성(콰이어·댄서·주인공·솔로), 개사의 분위기(차분·희망·따뜻·열정·경건), 곡 흐름(간주·첫 소절·반복되는 가사로 찾은 절정·끝), 대사·악기를 읽어 제안을 만듭니다. 제안은 수정요망 개수에 넣지 않고, 결과 화면의 '음향 · FD'와 '조명' 항목(칩에 '제안' 표시)과 총평, 피드백 메시지, 검토용 엑셀 총평 시트에 들어갑니다.

- 음향: 합창 마이크 개수(콰이어 6명당 1개 정도, 최종 수량은 TFT 음향팀과 확인), 노래하는 주인공·솔로의 무선 마이크(기본 2대), 간주·안무 구간 OFF와 가사 시작 ON, 절정에서 합창 볼륨, 대사·악기(DI·마이킹)
- 조명: 분위기에 맞는 상단 색과 밝기 범위, 분위기가 바뀌는 시점, 도입(간주는 어둡게 서서히 · 밝은 곡은 첫 소절부터 즉시), 절정에서 가장 밝게, 주인공·솔로의 Pin 자리, 안무 구간 무대 전체 70% 이상, 노래 끝 암전
- 지금 큐시트와 비교: 절정의 밝기가 도입보다 높지 않으면 함께 알려 줌

실제 학부 큐시트 내용은 사이트에 넣지 않았습니다. 예시는 모두 가상 학부입니다.

## AI 대안 기능 켜기 (선택)

규칙 기반 피드백과 피드백 반영본은 API 키 없이 동작합니다. Netlify 프로젝트 설정 → Environment variables에 `ANTHROPIC_API_KEY`(범위: Functions)를 넣고 다시 배포하면 '피드백 반영한 구글 시트 받기' 버튼 줄에 'AI 대안'이 나타나고, 반영한 대안은 반영본에 함께 들어갑니다. 모델은 `claude-opus-5-5`, 서버 측 대체 모델(`fallbacks: "default"`)을 켜 두었습니다. AI를 쓰면 무대별 큐시트 내용이 Anthropic API로 전송됩니다.
