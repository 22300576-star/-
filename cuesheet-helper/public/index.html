1. 기본 규칙

  • 양식을 그대로 유지합니다. 열을 추가하거나(예: 원곡 가사, 참고 이미지) 조명 칸을 합치지 말고, 필요한 내용은 비고에 적습니다.
  • 붉은색 안내가 있는 칸(Run Time~Details)은 빈칸 없이 채웁니다. 작성할 내용이 없으면 X, 앞 행과 같은 조명이 이어지면 유지로 적습니다.
  • 같은 무대 안에서 공통된 항목(항목·무대·대기 인원·음향·화면)은 셀 병합합니다. 조명은 행마다 따로 적습니다.
  • 아직 정하지 못한 부분은 '논의 중'이라고 적어 표시하고, 다음 차수까지 확정합니다.
  • 첫 두 행은 고정입니다: 학부 소개 및 투표(사회자) → 학부 인트로 영상(TFT 제작). 그다음부터 학부 순서를 적습니다.

3. Run Time 규칙

  • 표기: 00:00 ~ 00:04 (4초) — 시작, 끝, 단시를 모두 적습니다.
  • 기준: 학부 영상의 재생 시간입니다. 인트로 영상(TFT 제작)이 끝나고 학부 순서가 시작되는 순간을 00:00으로 잡으면 조명·음향팀이 영상 시간과 그대로 맞춰 볼 수 있습니다.
  • 앞 행의 끝 시각과 다음 행의 시작 시각이 같아야 합니다(빈 구간·겹침 없음). 무대마다 00:00으로 다시 시작하지 말고 전체를 이어서 적습니다.
  • 총 13분 = 인트로 영상 2분 + 무대 11분. 무대 시간 11분 초과는 절대 안 됩니다.
  • 조명·Details에 적는 시간도 Run Time과 같은 기준이어야 합니다. 곡 기준(노래 시작 = 0:00)이나 다른 영상 버전의 시간으로 적으면 큐가 어긋납니다.

4. 조명 — 2026 기준

2025년 큐시트의 조명(House / Stage / Pin1·Pin2 O/X)은 2026년과 다릅니다. 2026 큐시트는 아래 기준으로만 작성합니다.

무대 조명

무대 앞에서 무대를 향해 비추는 조명으로, 주로 인물을 비춥니다. 색보다 밝은 계열로 인물이 잘 보이게 쓰는 것을 권장합니다. 왼쪽 / 중앙 / 오른쪽 구역을 나누어 요청할 수 있습니다.

중앙 / 하얀색 / 100% (이 경우 왼쪽·오른쪽 무대 조명은 꺼짐)

상단 조명

무대 바로 위에서 아래로 비추며 무대에 색을 입혀 분위기를 만듭니다. 상단 왼쪽 / 중앙 / 오른쪽에 각각 색상과 밝기를 요청합니다.

상단 중앙 / 따뜻한 노란빛 / 70%, 상단 왼쪽·오른쪽 / 파란색 / 50%

핀조명 Pin1~4

  • 색 변경 불가 — ON/OFF와 밝기만 조절합니다.
  • 위치 고정 — Pin1 무대 왼쪽, Pin2 단상 앞 중앙, Pin3 무대 앞 중앙, Pin4 무대 오른쪽. 사람을 따라 움직일 수 없습니다.
  • 1명을 비출 때 가장 효과적입니다. 3명 이상은 무대 조명 구역으로 비추세요.

FX1 · FX2

  • 스트로브 · 고보(무늬 투사) · 무빙(좌우 교차·원 그리기) · 추가 핀(Pin1~4 위치가 아닌 곳) 중 2개만 골라 FX1, FX2로 지정합니다. 여러 효과를 묶은 하나의 연출은 FX 하나로 인정합니다.
  • FX는 Pin4 옆 Details에 적습니다. 예) 00:00~00:01 노래가 시작되면 1초간 스트로브 조명(FX1)을 틀어주세요.
  • 스트로브는 오래 쓰면 관객이 불편할 수 있어 짧게 씁니다.

조명 작성 팁

  • 전환 방식을 적습니다: 즉시 바뀌는지, 몇 초에 걸쳐 서서히 바뀌는지, 함께 끄거나 바꿀 조명은 무엇인지.
  • 시간은 영상 재생 시간(Run Time) 기준 시:분:초로 적습니다.
  • 시간으로 적기 어려우면 누구나 알 수 있는 객관적인 시점으로 적습니다. '분위기가 고조될 때' 대신 '사회자가 ○○라고 말한 직후', '출연자 전원이 무대 중앙에 정렬한 후'.
  • 색은 '파란색', '따뜻한 노란빛'처럼 적거나 #0C1F3F 같은 색상코드로 적습니다(코드와 실제 색은 조금 다를 수 있음). 밝기는 %로 적습니다(50%·100% 기준 사진 참고).
  • 리허설에서는 밝기·색상의 작은 조정만 가능합니다. 구성 자체를 바꾸기는 어렵습니다.

5. 음향 / FD

  • 어떤 장비를 몇 개: 합창 마이크 4개(단상 앞), 무선 마이크 n개, 유선 마이크 n개, 마이크 거치대, 악기(카혼 마이킹·기타 DI 등).
  • 누가: 무선·핸드 마이크를 쓰는 사람(주인공, 솔로 1·2). 솔로가 번갈아 쓰면 행마다 '핸드마이크 1 ON'처럼 적습니다.
  • 언제·어떻게(FD): 무대 사이에 마이크 세팅이 바뀌면 영상 송출 중에 무엇을 어디로 옮기는지 적습니다.
    예) 영상2가 송출될 때 무대 앞쪽에 있던 합창 마이크 4대를 단상 바로 앞까지 붙여 배치해주세요.
    예) 무대 중앙에 마이크 거치대 1개에 무선 마이크 1개를 꽂아 설치, 나머지 무선 마이크 1대는 무대 오른편 계단에서 기다리는 단원에게 전달.
  • 마이크를 쓰지 않는 구간은 X, 영상 구간은 영상 음향으로 나갑니다.
